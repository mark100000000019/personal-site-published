Dungeon crawler demo

A short grid-based first-person dungeon crawler, in the style of the classic Dungeon Master / Eye of the Beholder games — built with a coding agent as a "can we actually do this in plain HTML/CSS/JS" experiment, not a career section. Movement is tile-by-tile, turning is in 90° steps, and the view is redrawn from a small lookup table of wall segments rather than any real 3D — the same trick those original games used.

Find the lever, then the goblin blocking the way to the treasure. Controls: arrow keys / WASD, or the buttons below.
