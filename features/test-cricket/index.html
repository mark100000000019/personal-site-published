Test cricket

Test cricket gets written off as boring by people who've only ever seen the highlights — five days, no fixed number of overs, long stretches where nothing looks like it's happening. But the scoreboard is the least interesting part of it. Underneath a session that looks stationary — same total, same batters, nobody out — the balance of the game is usually moving: a bowler settling into a spell, a batter starting to middle it, a declaration being quietly set up three sessions in advance.

The widget below plays out a single Test match — illustrative, not a real one — session by session, with a running “momentum” line alongside the bare scorecard, so you can see the game swinging even when the total on the board barely changes. Drag the slider to jump around, or just let it play.
